# marketing/

GTM artefacts for AegisAI. Built from the launch plan in `~/.claude/plans/soft-launching-walrus.md`.

## What's here

| File | Purpose | How you use it |
|---|---|---|
| `index.html` | The single-page pitch site | Deploy to `aegisai.eu` via Cloudflare Pages |
| `one-pager.html` | Half-page sales sheet | Open in Chrome → Save as PDF → attach to every email |
| `demo-binder.html` | Real binder for fictional "Hellenic Atlantic Bank" | Generated by `npm run demo:binder`. Save as PDF for the most important asset in your pipeline |
| `pilot-loi.md` | Letter of Intent template (free pilot) | Fill placeholders, export to PDF, send via DocuSign / HelloSign |
| `crm-template.csv` | Pipeline schema | Import to Airtable / Notion as a starting CRM |
| `day-1-checklist.md` | Exact 4-hour kickoff sequence | Execute tonight |
| `outreach/01-linkedin-warm-intro.md` | DM template for Tier-1 LinkedIn contacts | Phase 1 of the launch plan |
| `outreach/02-cold-email-v1.md` | Cold email template + follow-up sequence | Phase 2 of the launch plan |
| `outreach/03-discovery-call-script.md` | 30-min first-call script | For every booked meeting |
| `outreach/04-linkedin-content-calendar.md` | 12 weeks of content prompts | Phase 3 — 3 posts/week |

## Regenerate the demo binder

The fictional bank's binder is regenerated from the live API in-process. Run it any time you change a policy pack, the DocGen template, or the evidence schema:

```bash
npm run demo:binder
```

Output is overwritten in `marketing/demo-binder.html`. Print to PDF.

## Deploying the landing page

The fastest path:

1. Put `marketing/index.html` (renamed `index.html`), `marketing/one-pager.html`, and `marketing/demo-binder.html` into a separate public repo (e.g. `aegisai-site`).
2. Connect to **Cloudflare Pages** — auto-deploy on push to main.
3. Custom domain → `aegisai.eu`.
4. Configure SPF / DKIM / DMARC in the same Cloudflare DNS.

5 minutes from zero to live.

## What goes on `aegisai.eu` and what doesn't

**Ships:** `index.html`, `one-pager.html`, `demo-binder.html` (and their PDF exports).

**Stays private:** the source code, `pilot-loi.md`, `crm-template.csv`, the entire `outreach/` directory. These are operational, not customer-facing.
